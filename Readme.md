# HR Attrition Analysis Dashboard (Excel)

## 📸 Dashboard Preview

![HR Attrition Dashboard](/dashboard_preview.png)

## 📌 Project Overview
This project presents an HR Attrition Analysis Dashboard built using Microsoft Excel to analyze employee attrition patterns and key workforce trends.

The dashboard provides insights into how factors such as department, job role, job level, overtime, work-life balance, and job satisfaction impact employee attrition.

This project is created for learning and portfolio purposes only.

---

## 📂 Dataset Information
- Dataset Name: IBM HR Analytics Employee Attrition & Performance
- Source: Kaggle
- Company Referenced: IBM

Disclaimer: This project is not affiliated with or endorsed by IBM.

---

## 📊 Key Metrics
- Overall Attrition Rate: 16%
- Employees Working Overtime: 28%

---

## 🔍 Key Insights
- Attrition is higher among employees working overtime
- Lower job levels (Level 1 & 2) experience the highest attrition
- Research & Development and Sales departments show maximum attrition
- Poor work-life balance significantly increases employee attrition
- Employees with moderate job satisfaction tend to leave more than highly satisfied employees

## 📈 Dashboard Features
- KPI cards for quick insights
- Interactive slicers (Gender, Department, Job Role, Job Level)
- Department-wise and role-wise attrition analysis
- Attrition trends by working years and job level
